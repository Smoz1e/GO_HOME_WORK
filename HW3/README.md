# Домашнее задание №3: тестирование и конкурентность

Задание продолжает сервисы из HW2. Оба сервиса этой версии находятся в HW3 и используют protobuf-контракт из `../HW2/gen/product/v1`.

Из папки HW3 запустите сервисы командой:

```bash
make run-all
```

Сервис товаров слушает gRPC на `:50051`, корзина — HTTP на `:8080`. Товары загружаются из `products.json`. Адреса можно изменить через `PRODUCT_GRPC_ADDR` и `CART_HTTP_ADDR`, путь к файлу — через `PRODUCTS_FILE`.

Проверки:

```bash
make test
make test-race
make bench
```

Для интеграционного теста оставьте `make run-all` работающим в другом терминале и выполните:

```bash
make test-api
```

При другом HTTP-адресе укажите `CART_HTTP_URL`, например `CART_HTTP_URL=http://localhost:18080 make test-api`. Интеграционный тест создаёт случайный ID пользователя и проверяет реальные gRPC- и HTTP-запросы. Тесты живых сервисов и конкурентного добавления лежат в `testdata`, поэтому обычный `make test` их не запускает. Генерация общего protobuf-контракта: `make generate`.

При чтении корзины сервис делает один gRPC-запрос на каждый SKU параллельно с общим таймаутом 3 секунды. Снимок корзины снимается под `RWMutex`, счётчики товаров обновляются атомарно.

## Бенчмарки

Замеры выполнены на Apple M4, Go 1.27.1, командой `GOMAXPROCS=1 make bench`. Цель `bench` включает флаг `-benchmem`. Версия «до» использовалась только для сравнения: блокировки карты были временно отключены, и race-детектор обнаружил `DATA RACE`. После замера блокировки восстановлены.

| Операция | До, ns/op | До, allocs/op | После, ns/op | После, allocs/op |
| --- | ---: | ---: | ---: | ---: |
| `BenchmarkGetProduct` | 16.28 | 1 | 16.00 | 1 |
| `BenchmarkAddToCart` | 366.6 | 5 | 384.8 | 5 |
| `BenchmarkGetCart` | 1367 | 20 | 1352 | 20 |

Разница в отдельном замере включает шум измерения; стоимость блокировки заметнее в `BenchmarkAddToCart`.
