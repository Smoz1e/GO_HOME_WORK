# Домашнее задание №4: SQL и базы данных

В папке находятся пять запросов по задачам. `setup.sql` создаёт таблицы и загружает данные из задания в пустую базу PostgreSQL.

Из корня репозитория выполните:

```bash
createdb hw4
psql -d hw4 -f HW4/setup.sql
for query in HW4/0*.sql; do psql -d hw4 -f "$query"; done
```

Первый запрос возвращает Бориса и Веру: оба являются самыми старшими пользователями Москвы. Пятый запрос также возвращает все заказы с минимальной подходящей ценой, если таких заказов несколько.
